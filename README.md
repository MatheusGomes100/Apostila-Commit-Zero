# Commit Zero — Guia Prático de Git & GitHub

Material didático da Oficina de Git e GitHub focado em ensino prático de controle de versão.

---

## Sobre o Projeto

Este repositório contém a apostila e os materiais de apoio da oficina. O conteúdo foi desenvolvido para guiar o estudante desde os primeiros comandos no terminal até o fluxo de trabalho colaborativo com repositórios remotos.

---

## Conteúdo Programático

- **Capítulo 1:** Instalação e configuração inicial do ambiente.
- **Capítulo 2:** Estrutura interna do Git, commits e histórico.
- **Capítulo 3:** Desfazer alterações e navegação temporal de código.
- **Capítulo 4:** *Branches*, resolução de *merge conflicts* e *Pull Requests*.
- **Capítulo 5:** Publicação e boas práticas de segurança em computadores compartilhados.

---

## Estrutura do Repositório

- `docs/`: Arquivo PDF da apostila completa.
- `src/`: Arquivos de código de exemplo utilizados nos exercícios práticos.
